# Changelog

All notable changes. Versions follow `MAJOR.MINOR.PATCH`; the model version is `__version__` in `src/<package>/__init__.py` and is written into `results/results.json`.

## 0.2.0 - 2026-11-05
- Model moved from the HTML prototype to a tested Python package (`src/media_buying_advisor`); the prototype keeps a JavaScript mirror verified by a parity test.
- Account data moved into `data/*.csv` with a data dictionary; actions, claim patterns, markets and all constants moved into `data/params.json` (single source of truth for code, prototype and paper).
- Fixed the ad-copy claim pattern "Sin comisiones": `0 ?%` also matched "100 % online"; it now requires a word boundary.
- Figures are generated by `make figures`; paper numbers come from `results/results.json`.
- Fixed cross-reference numbers of figures in the paper.
